# School Management System — CodeIgniter 3.1.11

A fully normalized, database-driven CodeIgniter 3.1.11 MVC application with Tailwind CSS UI.

## Features
- **Database Schema**: 25 normalized tables prefixed with `tbl_*` in MySQL.
- **Authentication**: Secure bcrypt password hashing with role-based access control.
- **17 CI Models**: Full CRUD operations, soft delete, and data relationships.
- **Dynamic Modules**:
  - Dashboard overview & KPIs
  - Student Information System & Admissions
  - Academic Structure (Years, Classes, Sections, Subjects)
  - Staff & Teacher Directories
  - Daily Attendance & Reporting
  - Fee Management & Transactions
  - Notices & Announcements
  - Certificate Generation & Reports
  - User Management & School Settings
